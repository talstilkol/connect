# 1. Connect — Discovery Cutoff v2 tool contract

## 1.1 Purpose

1.1.1 This contract freezes a clean Git input commit before Source Universe v4 generation.

1.1.2 It predeclares both Cutoff v2 evidence paths and every Source Universe v4 candidate, review and acceptance output path.

1.1.3 It is a local candidate-control contract. It is not Acceptance, independent review, trusted time or production authorization.

## 1.2 Invariants

1.2.1 Repository visibility remains `PUBLIC`; development freeze remains `ACTIVE`; Gate29 remains `BLOCKED`.

1.2.2 Tal is the sole active owner. No role split, Primary or Backup identity is implied.

1.2.3 Every declared Cutoff v2 and Source Universe v4 output path must be absent at observation time.

1.2.4 The product repository must be clean and working-file secret hygiene must pass.

1.2.5 The receipt records the exact Git commit, local discovery roots, remote Git refs, toolchain bytes, output registries and known limitations.

1.2.6 No source bytes, absolute host paths, credentials, private locators or customer data may appear in the public evidence package.

1.2.7 No randomness, cryptographic key, signature algorithm or new identity is generated by this toolchain.

## 1.3 Fail-closed behavior

1.3.1 An existing output, dirty worktree, missing registry, path escape, symlink-like unsafe path, registry mismatch, digest mismatch or unknown field blocks generation or verification.

1.3.2 GitHub API surfaces, pull-request refs, private source custody, official-source occurrence coverage, trusted time and independent review remain explicit blockers until separate evidence exists.

1.3.3 A locally verified package is labelled `CANDIDATE-NOT-ACCEPTED` and never advances Gate29.
