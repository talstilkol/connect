# 2. Normative semantics

2.1 four locator domains are disjoint: PlanningArtifactPath starts `docs/planning/`;RepositoryContentPath is normalized repository-relative and may include `.github/` or root files;PrivateEvidenceLocator never exposes a path or equality oracle in Public output;ExternalResourceLocator is an explicit HTTPS resource identity.

2.2 readers must discover the Git top-level, resolve its real path, verify origin identity `github.com/talstilkol/connect`, reject symlink escape and never infer repository authority from CWD alone.

2.3 canonical JSON profile PRCV4-CJ-1 is UTF-8;objects sorted by Unicode scalar-value code point after NFC;arrays preserve schema-defined order;duplicate keys, non-NFC strings, NaN, Infinity, negative zero, unpaired surrogates and non-integer numbers are rejected. Integers are base-10 JSON integers in the inclusive safe range.

2.4 every digest uses `UTF8("CONNECT-PRCV4:" + artifactDomain + ":") || canonicalBytes`;artifact domains are closed and distinct.

2.5 every output has one exact schema, sole authorized producer definition, input-object roots, implementation root, lifecycle head and evidence obligations. A declaration never supplies implementation or acceptance credit.

2.6 lifecycle is PROPOSED->EVIDENCED->INDEPENDENTLY-REVIEWED->ACCEPTED or any state->REVOKED/BLOCKED. Transitions require expected-old head CAS, authority root, trusted-time receipt, bounded expiry and append-only event root.

2.7 the accepted closure denominator is 93:59 inherited identities plus34 v3-review identities. Alias preservation for the first 32 inherited identities binds predecessor and v2 wrapper roots field by field.

2.8 a closure must contain accepted roots for every mapped Requirement. Plain IDs, Booleans, evidence presence or reader agreement cannot close a Finding.

2.9 negative vectors use only schema-valid domain fields and evaluator-derived terminals. Expected terminal is comparison data and never selects runtime output.

2.10 every unknown, inaccessible, stale, conflicting, mutable, untrusted-time, unsupported, rate-limited or unclassified state fails closed.
