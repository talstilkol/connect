## 6.2 Typed semantic edge schema

| Edge type | Allowed source class | Allowed target class | Authority credit | Mandatory invalidation behavior |
|---|---|---|---:|---|
| `MEMBER-OF` | immutable object | immutable manifest/package | 0 | member change invalidates container and descendants |
| `USES` | consumer object | exact dependency root/head | 0 | dependency change invalidates consumer |
| `VERIFIES` | admitted validator implementation | exact signed/serialized object | 0 | verifier/profile change invalidates result |
| `AUTHORIZES` | admitted L0 act or current delegated authority | exact Act/Permit/approval | 1 | source revocation invalidates target and descendants |
| `ISSUED-BY` | receipt/Permit/Appointment | exact admitted issuer | 0 | issuer loss invalidates issued object |
| `REVOKES` | admitted revocation event | exact authority root | -1 | target and complete descendant set become non-current |
| `SUPERSEDES` | immutable successor | immutable predecessor | 0 | predecessor remains historical and non-current |
| `INVALIDATES` | changed security head/event | exact dependent object | -1 | dependency cannot remain eligible/current |
| `WITNESSES` | independent witness receipt | exact checkpoint/ceremony | 0 | missing/conflicting witness blocks authority |
| `CONSUMES` | final transaction | exact one-use Permit | 0 | Permit becomes permanently unusable |
| `PUBLISHES` | committed transaction | exact immutable manifest/pointer | 0 | only confirmed transaction may make target visible/current |

6.2.1 `AUTHORIZES` is the only positive authority-credit edge. No `MEMBER-OF`, `USES`, `VERIFIES`, `ISSUED-BY`, `WITNESSES` or `PUBLISHES` edge can be reinterpreted as authority.

6.2.2 Exact instantiated graph rows are an unimplemented required Output. Prose and this schema do not create the missing external L0 edge.
