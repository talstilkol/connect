# 1. הרשאה להקמת סביבת עבודה ראשונה

1.1 בביקורת מסלול המשתמש הראשון מ־12.09.2026 נמצא שהקמת עסק דרשה משתמש וארגון Clerk מאומתים, אך לא הבחינה בין מנהל הארגון לחבר רגיל. משתמש ללא חברות ב־Connect יכול היה לקבל בעלות בעת ההקמה הראשונה של ארגון שטרם נקשר לעסק. אילוץ הייחודיות של שיוך הארגון מונע יצירת עסק נוסף לארגון שכבר נקשר; הוא אינו בודק מי רשאי ליזום את השיוך הראשון.

# 2. הכרעות

2.1 הקמה ראשונית דורשת `org:admin` בארגון הפעיל. מתאמי הזהות של Clerk מפיקים את הרשאת ההקמה מתוך `orgRole` של הזהות שאומתה. ערך חסר, חבר רגיל או תפקיד מותאם אינם מקבלים הרשאת הקמה. ההחלטה תואמת את מודל התפקידים הנוכחי של Connect; תמיכה בתפקיד מנהל מותאם תחייב הכרעה ומיפוי מפורשים.

2.2 ההרשאה היא מידע פנימי של השרת. הדפדפן אינו שולח אותה, ושכבת חוזה ה־API חוסמת את השדה גם בבקשות וגם בתגובות, כולל כתיב חלופי ושדות מקוננים. לא נשענים על Metadata שהמשתמש יכול לשלוח בטופס.

2.3 לאכוף את ההרשאה בפעולת ההקמה ובמבצע PostgreSQL לפני פתיחת טרנזקציה. שירות ההקמה הישן משתמש באותה בדיקה. בקשת הקמה ללא הרשאה נעצרת לפני יצירת עסק, בעלים, קבלה או רישום ביקורת.

2.4 ניהול עסק קיים נשאר כפוף לחברות ולהרשאות שנשמרו ב־Connect. הרשאת ההקמה אינה מחליפה אותן: חבר רגיל ב־Clerk יכול לבצע פעולות שהותרו לו בעסק קיים, ומנהל Clerk אינו מקבל עקיפה של הרשאות העסק.

2.5 לשמר את השמירה האטומית, המפתחות הדטרמיניסטיים, קבלות הבקשות החוזרות ואילוץ שיוך הארגון הקיימים. אין שינוי בסכמת המסד, בתלויות או בהגדרות חשבון חיות.

# 3. אימות וקבלה

3.1 שתי בדיקות רגרסיה נכשלו על הקוד הקודם: בקשת הקמה ללא הרשאה הגיעה למוטציה, ומבצע המסד פתח טרנזקציה. לאחר התיקון נבדקים חסימה לפני כתיבה, מעבר מנהל מאומת, דחיית ערכים חסרים או לא תקינים, ניהול עסק קיים ללא הרשאת הקמה, וחסימת הזרקת הרשאה מהלקוח. בדיקת גבול HTTP מחברת את מתאם Clerk, פתרון החברות ופעולת ההקמה.

3.2 קבלה חיה עדיין דורשת מנהל אמיתי המשלים הרשמה, ארגון ו־MFA, והקמת עסק ב־Staging. יש לבדוק גם הזמנת חבר רגיל ומעבר בין עסקים. בדיקות הקוד אינן הוכחה שהקבלה החיה הושלמה.

3.3 מקורות רשמיים שנבדקו ב־12.09.2026: [Clerk Auth object — orgRole](https://clerk.com/docs/reference/backend/types/auth-object), [תפקידי מנהל, חבר ותפקיד יוצר הארגון](https://clerk.com/docs/guides/organizations/control-access/roles-and-permissions). Clerk מגדירה כברירת מחדל `org:admin` ליוצר הארגון; הקישור בין התפקיד להרשאת הקמת עסק הוא מדיניות Connect המתועדת כאן.

3.4 אימות מקומי: 85 בדיקות ממוקדות עברו; שער השחרור עבר עם 4,622 בדיקות, TypeScript ובניות Vinext ו־Next.js Webpack. Lint הסתיים ללא שגיאות ועם 28 אזהרות קיימות. תוצאות CI, מיזוג ופריסה נבדקות ומתועדות בנפרד.
