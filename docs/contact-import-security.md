# חוזה אבטחה לייבוא אנשי קשר

תאריך אימות: 2026-08-17

## 1. מטרה

1.1 CSV ו־XLSX מומרים לאותו מבנה של כותרות ושורות.

1.2 לאחר ההמרה אין מסלול מיוחד ל־Excel: אותו Mapping, ‏Quality audit,
אימות E.164, ‏Consent fail-closed, ‏Tenant RBAC ו־Import job חלים על שני
הפורמטים.

1.3 קובץ המקור נקרא מקומית. רק שדות הפרופיל שמופו נשלחים לשרת לאחר
אישור מפורש; עמודות Consent גולמיות אינן מעניקות הרשאת דיוור.

## 2. Dependency review

2.1 `read-excel-file@9.2.0` נבחר כ־Reader צר ל־XLSX וננעל לגרסה מדויקת.
הוא אינו מוסיף תמיכה ב־XLS הבינארי הישן.

2.2 `fflate@0.8.3` ננעל ישירות ומשמש לבדיקת מבנה ה־ZIP לפני קריאת
הגיליון. ה־Lockfile שומר גם Integrity מסוג SHA-512 לכל Dependency.

2.3 מספרים נקראים תחילה כמחרוזות. כך מספר טלפון ארוך אינו עובר דרך
`number` של JavaScript ואינו מאבד דיוק. אפסים מובילים שכבר הוסרו בעת
שמירת התא ב־Excel אינם ניתנים לשחזור, ולכן אימות E.164 עדיין נדרש.

## 3. גבולות משאבים

3.1 קובץ מקור: עד 5 MiB ושם קובץ עד 255 תווים ללא תווי בקרה.

3.2 XLSX לאחר פתיחת ZIP: עד 25 MiB ועד 2,000 רכיבים פנימיים.

3.3 קובץ נתונים: עד 50,000 שורות, 100 עמודות, טווח של 500,000 תאים
ועד 2,000 תווים בתא.

3.4 השרת מאמת מחדש את מספר השורות, סיומת הקובץ ואינדקסי העמודות.
לכן קריאה ישירה ל־Server Action אינה עוקפת את גבולות הלקוח.

## 4. תוכן שנחסם

4.1 XLS ישן, קובץ ריק, סיומת אחרת או ZIP/XML פגום.

4.2 נוסחאות, Macros, ‏External relationships, ‏Embedded objects,
ActiveX, ‏Connections, הצפנה והצהרות XML מסוג DTD/ENTITY.

4.3 יותר מגיליון אחד, גיליון מוסתר, כתובות תא לא תקינות, שמות ZIP
כפולים או Path traversal ומידות גיליון שעלולות להקצות זיכרון חריג.

4.4 CSV שאינו UTF-8 תקין או שמכיל תווי Null.

## 5. התנהגות כשל

5.1 כל חריגה נכשלת לפני שמירת טיוטת Mapping ולפני קריאה לשרת.

5.2 המערכת אינה מתקנת בשקט קובץ חשוד, אינה מריצה נוסחה ואינה בוחרת
אוטומטית גיליון מתוך קובץ עמום.

5.3 הודעת השגיאה מסבירה למשתמש כיצד לשמור קובץ פשוט יותר; פרטי XML או
Stack trace אינם נחשפים בממשק.

## 6. בדיקות וראיות

6.1 בדיקות חיוביות מוכיחות המרה של CSV ושל XLSX לאותו מבנה שורות ושמירת
מספרים כמחרוזות.

6.2 בדיקות שליליות מכסות XLS ישן, UTF-8 פגום, שינוי קובץ במהלך קריאה,
קובץ גדול, נוסחה, Macro, קישור חיצוני, גיליון מוסתר או מרובה וטווח
תאים מסוכן.

6.3 Browser acceptance מקומי הושלם ב־2026-08-17 לקובץ XLSX תקין ולקובץ
עם Formula שנחסם. הראיה המלאה מתועדת ב־
`docs/contact-import-browser-acceptance.md`.

6.4 השלמה מקומית אינה ראיית Production. לפני Pilot נדרשת בדיקת Staging
עם קובץ מורשה אמיתי, Tenant אמיתי ו־D1 מבודד.
